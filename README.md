30集竖屏AI短剧（抖音/红果赛道）完整开发文档与剧本仓库。
类型：系统流 × 喜剧群像 × 末日生存｜混合流：情绪主线 + 悬疑辅线｜档位：标准档 120s｜变现：免费广告分账·多季IP。

## 世界观一句话

末日降临的方式很奇怪——一切人工密封包装的物资，打开的瞬间内容物随机化（盲盒化）；拆封预看不可、外力破坏包装内容物变废纸。营地 137 人靠一个前 200 万粉的开箱主播「何开盒」活着：他每天 30 点开盒值 + 盲盒直觉，是这个崩溃世界唯一稳定的「抽卡机器」。
